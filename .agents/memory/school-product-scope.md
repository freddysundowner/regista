Build a lean multi-school system for Kenyan schools. The main purpose is fee collection and automatic reconciliation; assessments, attendance, and the LeadsIntel WhatsApp bot are secondary modules.

**Why:** The user supplied the School Management System Technical Specification as the build requirements.

**How to apply:** Complete and verify each phase before starting the next: foundation; fees/ledger; M-Pesa/reconciliation; bot/notifications; banks; academics/attendance; reports/polish. Store configurable rules per school in the database. Use KES and Africa/Nairobi display time.

Do not build payroll, inventory/stores, library, hostel management, transport fleet management, timetabling, lesson plans, schemes of work, full portfolio management, general accounting/general ledger, procurement, or HR.

**Why:** These modules are explicitly out of scope in the user's specification.

**How to apply:** Do not add them as filler screens or recommend them as unsolicited next steps.
