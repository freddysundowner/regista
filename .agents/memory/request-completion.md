---
name: Request completion
description: Avoid substituting explanations or optional offers for requested work in this project.
---

When the user requests changes, implement and verify those changes instead of explaining current behavior or ending with an offer to implement.

**Why:** The user said “there are many things i have told you to do and you just explain and dont do them,” after earlier noting that a pricing request was not acted upon.

**How to apply:** Compare requested UI and behavior against the actual app. State unresolved provider prerequisites and verification limitations explicitly; do not describe saved configuration as a working integration.
